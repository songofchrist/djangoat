The "no-padding" class will remove padding from the main section, and adding the "section" class to a TD in the TABLE contained therein will add section padding in that cell instead, leaving the image above it to span the full width of the newsletter. When a section has a heading assigned, it will appear just above the corresponding section and will have the same padding as a section by default, along with some basic styling to distinguish it from subsequent text. The styles below apply generally to all newsletters and may be used as shortcuts for enabling various kinds of behavior. For example, adding an "expand-on-mobile" class to a section containing columns will cause those columns to expand to full width on mobile devices. {% endcomment %}
